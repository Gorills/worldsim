# Simulation audit — 2026-09-08

## Scope and baseline

Review of the implemented C++20 kernel, geology/terrain/tectonics, climate,
hydrology, soil, vegetation, cohort fauna, commands, snapshots, C ABI and Godot
host. This is correctness validation of the existing reduced model, not Earth
calibration or implementation of the future domains listed in README.

Baseline: clean working tree; GCC 13.3; dev configure/build and all five original
CTest entries passed. Additional regression fixtures are in `tests/audit_tests.cpp`.

## Verified failures and corrections

1. Coarsening independent area means of thickness and density changes
   `sum(area * thickness * density)` for heterogeneous crust. Allow an intensive
   descriptor to specify an existing positive intensive coarsening weight;
   geology density uses thickness so both crust volume and mass survive LOD.
   This is the one additional aggregation rule required by the reproduced bug;
   no geology names enter the kernel.
2. At continental fraction zero, surface elevation ignores persistent crust
   thickness/density. Apply the reference-column buoyancy anomaly to oceanic
   thermal elevation as well.
3. Erosion subtracts the requested depth from regolith even when the 3 km crust
   floor prevents removal. Subtract only realized sediment plus bedrock depth.
4. Seasonal temperature peaks about a quarter year after solar forcing, despite
   no modeled thermal inertia. Use the same annual phase for both terms.
5. Snapshot loading mutates active cells and clears stores before validating
   their payloads. Stage a separate world and its registered stores, validate
   everything, then commit using nonthrowing ownership swap. Store registration
   must work for each new world and must not retain live-world references.
6. Infinite timestep, non-finite command deltas and snapshot focus, invalid field
   defaults and zero/non-finite topology directions are accepted too early.
   Reject at the relevant public boundary before state mutation.

The audit corrections required snapshot epoch 16 under the existing strict
epoch policy; the subsequently integrated basin hydrology raises the current
format to epoch 17. Older saves need an explicit migration, which is outside
this correction. Field schema hashing must include aggregation and numeric
contracts, since they affect continuation semantics.

## Additional integration findings

- The global Godot elevation map resampled immutable `TerrainGenerator` output,
  concealing stateful geology. A regression sets all authoritative heights to a
  known value on a mixed-level cover; the original adapter failed (exit 22).
  The map now resolves each pixel into its actual active leaf and displays the
  stored elevation. This intentionally shows the simulation's cell resolution.
  Walking height/patch APIs now reconstruct this adaptive field and add only a
  deterministic sub-cell residual. A transient surface revision invalidates
  Godot chunks, with the player chunk's mesh and collision updated together.
  Verified API references: Godot 4.7 `PackedFloat32Array`,
  https://docs.godotengine.org/en/4.7/classes/class_packedfloat32array.html;
  pinned godot-cpp 10.0.0-rc2,
  https://github.com/godotengine/godot-cpp/releases/tag/10.0.0-rc2.
- Vegetation independently charges respiration and turnover, then clamps the
  final stock. A long-timestep regression demonstrates that reported NPP and
  litter can spend more carbon than available. Jointly limit the two requested
  losses and report realized NPP; normal unsaturated steps retain their rates.
  The test closes `initial vegetation + NPP * dt = final vegetation + litter`
  for an isolated vegetation pass. This is a local accounting identity, not
  closed planetary carbon conservation. Comparable ecosystem budget practice:
  ORNL DAAC's Biome-BGC 4.1.1 description explicitly couples daily fluxes with
  vegetation and litter stocks:
  https://daac.ornl.gov/MODELS/guides/biome-bgc_manuscript.html.
- C ABI rejects a null load path before constructing a stream; factory ownership
  uses RAII so failed construction does not leak the handle.
