# Third-party dependencies

WorldSim itself does not vendor third-party source in this archive.

The optional Godot adapter uses the official `godot-cpp` project and pins FetchContent to tag `10.0.0-rc2` (expected release commit `5ed72a0dc2517a8082598a950895c6b24e8aa282`):

<https://github.com/godotengine/godot-cpp>

`godot-cpp` is distributed under the MIT license; consult its repository for the authoritative license text and notices. Godot Engine itself is not bundled in this archive.
